# Profile icon proposals

Three alternatives for the current two Claude accounts and one Codex account.
These files are proposals; no profile configuration has been changed.

- A / a-number-badges: provider mark with a contrasting account-number badge.
- B / b-account-colors: large provider marks with coral/lavender/mint account colors.
- C / c-number-first: a large central number surrounded by the provider mark.

Each set has claude-1.png, claude-2.png and codex-1.png. Numbers are per
provider, not the combined config slot: Codex 1 is the current third slot.

Use the 64 x 64 transparent PNG files for profile_<N>_icon. Matching SVG
files are editable masters; the app reads the PNG files. The comparison
includes 64px views and 14px samples on both dark and light backgrounds;
open comparison.png at 100% zoom to inspect the actual app-size samples.

Provider marks were adapted from the locally installed Claude Code
extension's claude-logo.svg and Codex extension's blossom-black.svg.
The account badges, color palettes and layout are proposal designs.
These were built as vector assets and rendered locally to PNG.
