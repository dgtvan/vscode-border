# Number-first profile icons

Revision of proposal C with account numbers enlarged from 34 to 44 SVG units
(about 29%). The icon canvas and the app's display size are unchanged.

- `claude-1.png`: first Claude account.
- `claude-2.png`: second Claude account.
- `codex-1.png`: first Codex account (the third configured profile).

Use the transparent 64 x 64 PNG files as `profile_<N>_icon`. Matching SVG
files are editable masters. Claude uses a coral provider mark; Codex uses mint.
Numbers identify accounts within each provider.

Provider marks are adapted from the locally installed Claude Code extension's
`claude-logo.svg` and Codex extension's `blossom-black.svg`, as in proposal C.
