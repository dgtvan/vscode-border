# Selected profile icons: side numbers

Selected design (option A): a cropped provider mark on the left and a large
account number on the right. The number uses 56 SVG units on a 64 x 64 canvas.

- `claude-1.png`: first Claude account.
- `claude-2.png`: second Claude account.
- `codex-3.png`: Codex account in the third configured profile.
- `codex-1.png`: alternative Codex icon with number 1.

Use the 64 x 64 PNGs as `profile_<N>_icon`. Corners are transparent and the
dark tile keeps the white number legible on both light and dark backgrounds.
Matching SVGs are editable masters. The selected sequence is Claude 1,
Claude 2, Codex 3. Coral and the cropped sunburst identify Claude, while mint
and the cropped knot identify Codex.

Provider marks are adapted from the locally installed Claude Code extension's
`claude-logo.svg` and Codex extension's `blossom-black.svg`, as in proposal A.
